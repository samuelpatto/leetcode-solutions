## 🧠 Padrões Mapeados

- **Hash Map / Dictionary:** Busca instantânea $\mathcal{O}(1)$ e contagem de frequências.
- **Two Pointers:** Manipulação de coleções e alteração *in-place* com memória $\mathcal{O}(1)$.
- **Sliding Window:** Redução de sub-arrays/sub-strings de $\mathcal{O}(N^2)$ para $\mathcal{O}(N)$.
- **Binary Search:** Busca logarítmica $\mathcal{O}(\log N)$ em listas ordenadas.
- **Stack:** Estrutura LIFO para validação de escopos e navegação.
